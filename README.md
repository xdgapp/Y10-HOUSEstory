# HOUSEstory
atar computer science unit 1 game programming project
- 75% (avg: 71%)
- 19/02/2024 - 19/03/2024

- was pretty proud of this one, i still enjoy my writing even if it comes off as rather obnoxious (15-year-old me was SO neurotic, Seven different endings? really?)
- however, it is Terribly buggy n a pain to actually play

- at the time i was rly into text adventure games like zork n hitchhikers guide (idk i fell into very interesting rabbit holes as a child), so i based it around those sort of games, especially with their very narrative-driven nature (i particularly tried to emulate douglas adams' clever writing, no idea how well i did)
- funnily enough, i also subconsciously took inspiration from those games with how often the player would die, playtesters (aka my friends) got pissed at how they would die seemingly out of nowhere, n how annoying it was to just restart n do everything all over again
- however, i too was pissed off when i first got killed by the troll in zork (for what seemed to be no reason) or by the random brick in hitchhikers guide, so ig it just cemented in my head that these sort of frustrating things were essential to these 'interactive fiction' games

- planned out the layout of the 'map' or game environment with trizbort, which i actually used when i played other text adventure games (too lazy to draw maps w pen n paper)
- i might actually adapt this story in something like twine, i rly did used to enjoy creative writing a lot, i shld get back into storytelling in general

for the rest of the year, this idea of a text adventure game kept brewing in my head, leading me to make Another one of these for a unit 3 assignment, a Spiritual Successor if u will ..
